# UNI__Simulated-Annealing-for-Solving-Sudoku
A Sudoku solver written in C that uses the Simulated Annealing optimization algorithm to find solutions to Sudoku puzzles.
> Compsci course: Second year, second semester 
- sa solver algorithm is in [main.c](https://github.com/werixx1/Simulated-Annealing-for-Solving-Sudoku-In-C/blob/main/src/main.c) 
- unsolved sudoku board is generated by functions from previous project [link](https://github.com/werixx1/terminal-sudoku-in-c) that are in [load_sudoku.c](https://github.com/werixx1/Simulated-Annealing-for-Solving-Sudoku-In-C/blob/main/src/load_sudoku.c)
- execute: ```gcc main.c load_sudoku.c utils.c -o solve_sudoku``` then ```./solve_sudoku```
